## 지금 단계

**제작 로드맵 0단계: 레포 준비.** 기반 결정(문서 체계, 아키텍처, 폴더 구조, 개발 환경, 코드·테스트·git 규칙, 관절 구동, 손목 형식, 정밀도 기준, 작업 공간, 관절 구조, 골격)은 끝났다. 결정 기록은 [decisions/](decisions/)에 있다.

- 폴더 구조, Python 환경, 도구 설정, 구조 테스트는 해 두었다.
- 골격 설계에 쓸 검토 도구를 만들었다: 로봇 기술 → FK, MJCF(막대 모델), URDF, 해석적 IK, 버팀 토크, 백래시 끝점 오차 (`packages/design`). 관절 구동([0011](decisions/0011-joint-drives.md))과 손목 형식([0013](decisions/0013-wrist-type.md))을 이것으로 정했다.
- 치수 값 파일의 뼈대를 만들었다 ([0006](decisions/0006-data-and-pipeline.md)): `params/arm.toml`, `params/servos.toml`, `data/measured.toml`을 읽어 검사하고 로봇 기술로 바꾼다 ([software.md](software.md#하나의-치수-값에서-모든-결과물을)).
- 출력 설정을 정했다 (구조 부품은 0.20mm Strength, [manufacturing.md](manufacturing.md#출력-설정)). 1차 공차 시험편(M3 볼트 구멍, 너트 홈)을 만들었다 (`build/coupons/`).
- 서보 세 종의 공식 도면을 찾아 기구 치수를 정리했다 ([hardware.md](hardware.md#기구-치수)). 2차 공차 시험편(STS 서보 틀, 혼 자리)도 도면 치수로 만들었다.
- 작업 공간을 정했다 ([0014](decisions/0014-workspace-layout.md)): 40 mm 박스, 2 × 2 팔레트 4층, 작업 반지름 25 cm.
- 관절 구조를 정했다 ([0015](decisions/0015-joint-structure.md)): J2~J6는 ㄷ자 브래킷이 서보의 출력 혼과 뒷면 혼을 잡고, J1은 크로스 롤러 베어링 RU42로 받친다. 영점은 지름 3 mm 강철 핀으로 잡는다.
- 출력 전 확인 규칙을 정했다 ([design.md](design.md#출력-전-확인)). 그 계산 검사로 실제 서보 외형과 관절 구조를 넣은 골격 배치를 검토하고 (`studies/packaging.py`) 골격을 정했다 ([0017](decisions/0017-skeleton.md)): 어깨 높이 120, 위팔 200, 아래팔 170, 손목 오프셋(0019에서 63 · 63 · 50 mm로 늘렸다), 관절 범위, 포인터 시험 자리. STS 서보 두께는 자료(2D 도면과 STEP)가 서로 달라 두 가지로 다 검사했다.
- D405의 공식 사양(고정 구멍, 커넥터, 시야, 해상도별 최소 거리)을 확인했다 ([hardware.md](hardware.md#d405)). 카메라 자리를 정했다 ([0018](decisions/0018-camera-mounts.md)): D405는 손목에, USB 카메라는 책상의 카메라 기둥에 고정한다. 기둥 자리는 시야, 작업 자세, 캘리브레이션 자세를 계산해 골랐다 (`studies/cameras.py`).
- 부품 설계 전에 다른 데스크톱 로봇팔과 MakerWorld 모델을 조사해, 가져올 점과 피할 것, 협동로봇처럼 보이게 하는 외형을 정리했다 ([references.md](references.md)). 그 결과로 출력 전 확인에 링크·브래킷 휨 계산과 조립 순서 확인을 더했다 ([design.md](design.md#출력-전-확인)).
- 외형을 UR식으로 정했다 ([0019](decisions/0019-ur-look.md), `studies/covers.py`): 관절마다 축을 감싸는 원통(가운데 고리는 부모 링크, 양 끝 뚜껑은 자식 링크), 관 링크, 손목 원통 사이의 목, D405 받침판. 원통이 손목에 다 들어가도록 손목 오프셋을 63 · 63 · 50 mm로 늘렸다. 버팀 토크는 정격의 0.72배 안이고, 형상에 없는 무게(케이블, 나사, 흡착 튜브)는 플랜지 기준 약 116 g까지 여유가 있다. 링크 휨 계산도 이 검토에 넣었다.

## 제작 로드맵

이 순서로 진행한다.

0. **레포 준비**: [0007](decisions/0007-repo-structure.md)의 폴더 구조와 [0008](decisions/0008-environment-and-packages.md)의 Python 환경, 치수 값 파일의 뼈대를 만든다. SO-101에서 서보를 빼고, 서보 모델마다(STS3215, STS3250, 도착하면 ST-3120) 실제 치수와 무게를 잰다. 억지로 끼워 둔 STS3250은 서보를 비틀지 말고 출력 부품을 잘라 내서 뺀다. 출력 공차 시험편을 뽑아 재서 공차 값을 정한다 (시험편 종류는 [manufacturing.md](manufacturing.md#공차)).
1. **골격 설계**: 축 배치와 링크 길이를 정한다. 관절별 토크와 오차를 계산하고, MuJoCo 막대 모델로 작업 범위, IK, 특이점을 확인한다. 이 단계에는 아직 부품 모양이 없다. 이 단계를 하는 동안 2~3단계 부품을 주문한다.
2. **서보와 연결 준비**: 서보 ID를 정하고, EEPROM 값(특히 P 게인과 불감대), 서보 자체의 보호 설정, 전압판과 펌웨어 버전을 읽어 확인하고 설정한다. 다이얼 게이지로 관절의 틈을 다시 잰다 ([0011](decisions/0011-joint-drives.md)). 서보 7개로 통신 속도를 재서 실행 루프 주기를 정한다. 모터 프로세스와 안전 기능을 만들고, 실물을 처음 움직이기 전에 [0009](decisions/0009-control-architecture.md)의 시험을 통과한다. 카메라용 라즈베리파이를 준비하고 연결 구조 시험을 한다 ([0005](decisions/0005-connection-architecture.md)).
3. **관절 하나 시험**: 서보, 반대편 받침, 마스터링 핀, 상자 링크를 넣은 관절 하나를 출력한다. 흔들림, 백래시, 처짐을 재서 이전 프로젝트보다 나은지 확인한다. 서보 대신 출력한 서보 모형을 넣어 프레임의 휨만 따로 재고, 서보를 넣고 다시 재서 둘을 나눈다 ([references.md](references.md)). 하중을 건 채 30분 버티게 두고 서보 온도와 처짐 변화도 잰다 (PLA는 55~60°C부터 물러진다).
4. **손목과 그리퍼 교체부**를 만든다.
5. **팔 전체**를 설계하고 출력하고 조립한다.
6. **실물과 시뮬레이션 연동**: 같은 제어 코드로 실물과 시뮬레이션을 돌리고 캘리브레이션한다.

## 남은 질문

골격 설계 전까지 정한다. Claude가 근거와 함께 하나씩 제안한다.

- **관절 범위와 배선**: 서보 케이블, 흡착 튜브, D405 케이블이 회전축을 지나간다. 관절 범위, 배선 경로, 흡착 펌프 위치를 같이 정한다. 참고 설계에서 본 후보 ([references.md](references.md)):
  - J1에 기계 멈춤을 두어 한 바퀴 넘게 돌지 않게 한다 (PAROL6).
  - 흡착 튜브가 케이블을 잡아 주게 한다 (PAROL6).
  - 배선한 뒤 범위 끝까지 돌려 보고 덮는다 (ElRobot).
- **그리퍼 교체부 첫 버전**: 처음 구상(bayonet, 래치, 전기 접점, 공기 통로)을 다 넣을지, 맞춤 핀 2개와 손으로 돌리는 나사 2개로 단순하게 시작할지 정한다 ([design.md](design.md#그리퍼-교체-구조)). 새 후보는 so101-toolchanger 방식이다: 강철 핀 세 개를 V홈에 앉히고, J6로 돌려 잠근다 ([references.md](references.md)).
- 흡착 부품 사양(펌프 유량, 흡착컵 지름)과 펌프·밸브 제어 방법. OpenRB-150으로 하면 펌웨어가 하나 더 생기므로 USB 릴레이 같은 단순한 방법과 비교한다.
- 평행 그리퍼의 가이드 방식과 열림 폭. 참고 설계의 후보는 세 가지다. 어느 것이든 닫는 쪽 힘은 전류로 제한한다.
  - 출력 레일에서 피니언 하나가 랙 두 개를 민다 (ElRobot pgripper).
  - 지름 6 mm 봉 두 개 위로 미끄러진다 (robonine).
  - MGN7 또는 MGN9 리니어 레일 (MakerWorld, reBot).
- 제어 세부: 실행 루프 주기(서보 측정 후), 메시지와 궤적 형식(서보와 연결 준비 때). 구조는 [0009](decisions/0009-control-architecture.md), IK 방식은 [0008](decisions/0008-environment-and-packages.md). 이전 프로젝트 코드는 이어 쓰지 않고 새로 짠다.
- **USB 카메라 하나로 하는 박스 쌓기**: 기둥의 USB 카메라만으로 박스 쌓기가 되는지 정한다. 집는 곳에 아무렇게나 놓인 박스를 찾아 쌓는 경우까지 본다. 기둥을 비스듬히 볼지, 가로 팔로 위에서 볼지도 이때 고른다 ([0018](decisions/0018-camera-mounts.md)). 기둥을 설계하기 전에 정한다.

## 확인할 것

- 서보 사양: [hardware.md](hardware.md#서보-사양)에 정리했다. STS3250의 C001/C002 차이는 확인하지 못했다 (서보의 모델 번호 레지스터로 확인할 수 있다). ST-3120은 받으면 모델 번호 레지스터를 읽고, 혼(FT110M)과 뒷면 혼이 들어 있는지 본다. 혼이 없으면 관절 시험 전에 따로 사고, 뒷면 혼이 없으면 그 자리는 MR106ZZ로 받친다 ([0015](decisions/0015-joint-structure.md)). 치수와 무게는 사양표를 믿지 않고 실물을 잰다 (제작 로드맵 0단계).
- 예산 견적: 구매 후보를 다 더하면 30만 원을 넘을 수 있다 (서보는 꼭 필요하면 따로 더 쓸 수 있다, [0004](decisions/0004-purchasing.md)). PETG·TPU 롤이 정말 필요한지를 포함해 골격 설계 전에 대략 견적을 낸다 (가격 조사).
- 카메라용 파이의 pyrealsense2 설치 방법: hori2에 빌드해 둔 것을 그대로 쓸 수 있는지 먼저 보고, 안 되면 다른 후보를 시험한다 ([0007](decisions/0007-repo-structure.md)).
- 베이스를 물릴 클램프의 크기와 책상 두께 (베이스 설계 전).
