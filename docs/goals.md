# 목표

## 무엇을 만드나

뱀부랩 P1S로 출력한 부품과 이미 가진 Feetech 서보로 6축 로봇팔을 만든다. 협동로봇처럼 보이고 움직이는 "그럴듯한" 팔이 목표다.

- 설계는 코드 CAD(build123d)로 한다. 설계 코드는 Claude가 쓰고, 화면 확인과 출력·조립·실측은 직접 한다.
- 같은 치수 값 하나에서 출력용 부품, 조립 화면, URDF, MuJoCo 모델, 부품표를 함께 뽑는다. 실물과 시뮬레이션이 어긋나지 않게 하려는 것이다. 흐름은 [software.md](software.md)에 있다.
- 기한은 없다. 산업용 스펙은 목표가 아니다.

## "그럴듯한" 팔의 기준

| | 기준 |
|---|---|
| 구조 | 6축답게 손목이 짧고, 베이스와 손목 롤이 넉넉히 돈다 |
| 움직임 | 작업 범위 대부분에서 IK가 풀린다. 손끝을 한 점에 둔 채 자세만 바꿀 수 있고, 직선 이동이 매끄럽다 |
| 정밀도 | 같은 자리로 돌아왔을 때 흔들림이 이전 프로젝트보다 확실히 작다. 실제로 얼마나 나오는지는 만들어서 잰다. 기준과 재는 방법은 다시 정한다 (아래 참고) |
| 외형 | 케이블이 밖으로 덜렁거리지 않고 덮개 안으로 지나간다. 서보와 나사는 덮개로 가려 협동로봇처럼 깔끔하게 보인다 |
| 확장 | 그리퍼를 바꿔 달 수 있고, D405를 손목에 달 수 있고, MuJoCo 모델이 있다 |

정밀도 기준은 골격 설계 전에 다시 정한다 ([status.md](status.md#남은-질문)). 처음에는 "이전 오차의 절반"을 목표로 잡았다. 그런데 이전 오차(hand-eye σ 7.5 mm, [background.md](background.md))는 반복 정밀도가 아니라 절대 정확도와 카메라 오차가 섞인 캘리브레이션 잔차라서, 같은 잣대로 비교할 수 없다. 그래서 반복 정밀도와 절대 정확도를 따로 정의하고 재는 방법까지 정한다. 서보 한 스텝(0.088°)이 팔 끝 331 mm에서 약 0.5 mm라서, 반복 정밀도를 이보다 훨씬 작게 잡을 수는 없다.

## 대표 작업

작은 박스를 집어 팔레트처럼 쌓는 미니 팔레타이징. 산업용 팔레타이징을 책상 위에서 작게 해 보는 것이다.

팔레타이징은 도구가 늘 아래를 향해서 6축 팔의 자세 바꾸기를 시험하지 못한다. 그래서 6축 확인 작업을 따로 둔다.

- **포인터 시험**: 끝을 한 점에 고정한 채 자세만 바꾼다.
- **비전 파지**: D405로 비스듬히 놓인 물체를 찾아 잡는다.

## 작업 공간

- 작업대는 약 55 × 34 cm다 (이전 프로젝트와 같은 자리).
- 베이스는 책상에 클램프로 물려 고정한다.
- 데스크톱 PC는 로봇 책상에서 3~5 m 떨어져 있다. 연결 구조는 [0005](decisions/0005-connection-architecture.md)에 있다.
