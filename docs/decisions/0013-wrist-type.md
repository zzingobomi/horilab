# 0013. 손목 형식과 D405 자리

- 상태: 제안
- 날짜: 2026-11-07

## 배경

- [0001](0001-inherited-decisions.md)은 "손목은 가능하면 구형(롤-피치-롤), 어려우면 오프셋 작은 UR형", "D405는 로봇 쪽 플랜지에 단다"를 이어받았다. 손목 형식은 골격 설계 전에 두 형식을 수치로 비교해 정하기로 했다 ([design.md](../design.md#기구-원칙)).
- 해석적 IK(EAIK)가 두 형식을 다 풀어서, IK 때문에 구형 손목을 고를 이유는 없어졌다 ([0008](0008-environment-and-packages.md)).
- 도구가 아래를 향한 자세에서는 손목 관절의 백래시가 정밀도를 크게 깎는다 ([0011](0011-joint-drives.md)).
- 비교 코드: `uv run python -m horilab_design.studies.wrist_type`. 어깨, 위팔(20 cm), 아래팔(18 cm), 질량은 같고 손목만 다르다. 구형 손목은 손목 중심→플랜지 6 cm, UR형은 손목 오프셋 5 cm씩으로 어림했다 (STS3215 크기). 손목은 늘 같은 쪽 해(J5 > 0)를 쓴다.

## 비교

| 기준 | 구형 손목 | UR형 |
|---|---|---|
| 박스 쌓기 자세(반지름 12~30 cm)에 닿음 | 162/162 | 162/162 |
| 손목 백래시(±0.87°)가 TCP를 흔드는 양, 반지름 30 cm | J4 1.5 mm, J5 1.8 mm | J4 1.8 mm, J5 1.7 mm |
| 도구가 아래일 때 손목 관절의 중력 토크 | J4, J5 모두 0이라 백래시가 뜬다 | J4는 손목 무게가 늘 같은 방향으로 누른다 (0.14~0.19 N·m, J6를 돌려도 그대로). J5는 0이다 |
| D405를 비켜 달아 백래시를 누를 때 | 플랜지에 달면 J6를 ±45~90° 돌릴 때 방향이 뒤집힌다 | J6 앞 손목 하우징에 4.5 cm 비켜 달면 J6를 어떻게 돌려도 J5에 0.026 N·m가 같은 방향으로 걸린다 |
| 손목 특이점과의 거리 (박스 쌓기 자세의 \|sin J5\| 최소) | 0.49 | 1.00 (J5가 늘 90°) |
| 포인터 시험: 한 점에 TCP를 둔 채 도구를 기울이는 범위 | 모든 방향으로 60°까지 | 모든 방향으로 90°까지 |
| 서보 배치 | 세 축을 한 점에 모으려면 서보 몸체를 피해 가야 해서, 손목이 커지거나 기어·벨트가 필요할 수 있다 | 관절마다 서보가 다음 링크를 바로 돌린다. 같은 관절 모듈을 이어 붙이는 설계 방식([design.md](../design.md#설계-방식))과 맞는다 |
| 겉모습 | 산업용 로봇 | UR 같은 협동로봇 |

D405 자리:

| 대안 | 장점 | 단점 |
|---|---|---|
| 로봇 쪽 플랜지 (J6와 함께 돈다) | 그리퍼와 카메라의 상대 위치가 늘 같다 | D405의 뻣뻣한 USB 3 케이블이 J6 회전축을 지나 관절을 민다. J6를 돌리면 무게로 누르는 방향이 바뀐다 |
| J6 앞 손목 하우징 (J6와 함께 돌지 않는다) | J5 백래시를 늘 같은 방향으로 누른다. 케이블이 J6를 지나지 않아 J6 범위와 정밀도에 유리하다. 그리퍼를 바꿔도 hand-eye 캘리브레이션이 유지되는 건 같다 | J6를 돌리면 그리퍼가 카메라 화면 안에서 돈다 (J6 각도로 계산한다). 어떤 J6 각도에서는 그리퍼가 시야를 가릴 수 있다 |

## 결정 (제안)

- 손목은 UR형으로 한다 (J2∥J3∥J4, J5⊥J4, J6⊥J5). 손목은 늘 같은 쪽 해(J5 > 0)를 쓴다.
- D405는 J6 앞 손목 하우징에 J5 축에서 비켜 단다.
- 손목 오프셋은 서보 배치가 허락하는 만큼 작게 한다.

## 근거

- 닿는 범위와 손목 백래시의 크기는 비슷하고, 나머지 기준(손목 백래시를 누르는 힘, 특이점과의 거리, 포인터 시험, 서보 배치, 겉모습)에서 UR형이 낫다.
- UR형에 D405를 손목 하우징에 달면 J4와 J5의 백래시를 모두 늘 같은 방향으로 누른다. 0011의 대책과 합치면 J1(스프링), J2·J3(팔 무게), J4(손목 무게), J5(D405 무게)가 모두 한쪽으로 눌리고, J6는 TCP가 축 위에 있어 위치를 흔들지 않는다.
- 구형 손목의 장점(위치와 자세를 따로 풀 수 있다)은 EAIK가 UR형도 풀어서 의미가 줄었다.

## 영향

- 채택하면 0001의 손목 형식과 D405 자리 항목은 이 기록으로 대체된다.
- [0011](0011-joint-drives.md)의 J4·J5 대책(플랜지에 D405를 비켜 달기)은 이 기록으로 바뀐다.
- [design.md](../design.md)의 손목 형식과 그리퍼 교체 구조(D405 위치)를 고친다.
- 오프셋과 서보 배치는 골격 설계에서 정하고, 같은 비교를 다시 돌려 확인한다.
- 0.026 N·m 같은 작은 힘으로 백래시가 붙는지는 재 봐야 한다 ([0012](0012-precision-metrics.md)의 다이얼 게이지).
