# 0032. 실행 루프: 할 일 목록과 만드는 순서

- 상태: 채택
- 날짜: 2026-11-14

## 배경

- [0009](0009-control-architecture.md)는 실행 루프의 자리(Rust 컨트롤러), 받는 명령(시간이 붙은 관절 궤적), 안전 처리를 정했다. 그 뒤 실행 루프가 할 일이 여러 기록에 흩어졌다: 관절마다 토크 한도([0027](0027-general-purpose-review.md)), 온도가 오르면 쉬는 자세로 내리기([0028](0028-ur-style-joints.md)), 처짐 보정([0012](0012-precision-metrics.md)), 같은 방향에서 다가가기([0011](0011-joint-drives.md)), 그리퍼 서보([0023](0023-robot-controller.md)), 서보 보호 처리([0024](0024-servo-bus.md)).
- 서보 버스, 관절 층(토크 켜기와 이어받기, 한계 밖 목표 거르기, 통신 실패에 멈춤, 보호 비트와 위치 오프셋 검사), 실물 동작에 맞춘 가짜 서보는 있다 (0024). 그래서 실물 없이 루프를 만들고 시험할 수 있다.
- 주기를 정할 서보 7개의 Rust 통신 시간과, 우분투 26.04를 깐 컨트롤러 파이의 지연은 아직 재지 않았다 (ST-3120이 온 뒤, hori3).

## 결정

### 할 일 목록

| 할 일 | 정한 것 | 아직 정할 것과 정하는 때 |
|---|---|---|
| 한 박자 | 서보 모두의 상태(레지스터 40~70: 토크 스위치, 목표, 위치, 속도, 부하, 전압, 온도, 상태 바이트, 움직임, 전류)를 동기 읽기로 읽고, 검사한 뒤, 목표 위치를 동기 쓰기로 보낸다. 토크 스위치를 읽어야 서보 전원이 꺼졌다 켜진 것(토크가 꺼진다)을 안다 | 주기: 서보 7개의 Rust 통신 시간을 잰 뒤. Python으로 잰 한 박자(동기 쓰기 + 동기 읽기)가 중간 2.4~2.8 ms라 100 Hz가 후보다 (0024) |
| 궤적 실행 | 시간이 붙은 관절 궤적을 받아 박자마다 그 시각의 목표를 보낸다. 지금 위치에서 시작하고 관절·속도 한계 안인 궤적만 받고, 넘으면 실행 전에 통째로 거부한다 (0009) | 궤적의 모양과 보간 (rsruckig, [0025](0025-controller-on-pi.md)): 루프를 만들며 |
| 정지 | 명령 하나로 감속해 그 자리에서 버틴다. 경로 계획이나 조종하던 연결이 끊겨도 같다 (0009, 0023) | 감속의 크기: 팔 시험으로 |
| 서보 보호와 통신 | 박자마다 상태 바이트를 보고, 비트가 켜지면 고장이다: 새 궤적을 받지 않고 버티며 알린다. 과부하로 묶인 서보는 원인을 없앤 뒤 사람이 토크를 껐다 켜서 푼다. 한 서보와 3번 잇달아 통신하지 못하면 멈춘다 (0024, 관절 층에 있다) | 없다 |
| 온도 | 서보 온도가 기준을 넘으면 알리고, 더 넘으면 쉬는 자세로 내린 뒤 버틴다 (0028) | 기준: 다 만든 팔에서 서보가 읽는 온도와 덮개 안 온도를 같이 재서, 덮개와 부품이 무르기 전으로. 쉬는 자세: 설계에서 (토크 없이 기대 둘 수 있는 접은 자세, 0027) |
| 관절마다 토크 한도 | 부딪힐 때의 힘을 줄이려고, 관절마다 버티는 데 드는 토크에 여유를 더한 값을 토크 한도로 쓴다 (0027). 값은 로봇 설정에 둔다 | 값: 팔 전체 모델의 버팀 토크로 잡고 다 만든 팔에서 확인 |
| 처짐 보정 | 버티는 동안 서보가 읽은 위치와 목표의 차이로 목표를 고친다. 상대 정확도 목표의 조건이다 (0012). 루프에 보정 자리를 두고 처음에는 끈다 | 목표 고치기와 서보 I 게인 가운데 무엇으로 할지: 다 만든 팔에서 둘을 재서 |
| 같은 방향에서 다가가기 | 정밀하게 갈 때 마지막 접근을 정한 방향에서 한다 (0011). 경로 계획의 일이고, 루프는 받은 궤적을 따른다 | 접근 길이: 반복 정밀도 시험으로 |
| 그리퍼 서보 | ID 11부터이고, 관절과 같은 버스와 박자로 다룬다 (0024, [design.md](../design.md#그리퍼-교체-구조)). 로봇 설정에 그리퍼 칸을 더한다 | 그리퍼 명령의 모양: 0023의 메시지를 만들 때 |
| 자기 충돌과 안전 평면 | 실행 전에 궤적을 통째로 검사한다 (0009). 링크 도형은 로봇 설정에 둔다 | 도형: 팔 부품이 정해진 뒤 |
| 전압 | 박자마다 읽어 기록한다. 움직일 때 처지는 전압으로 [0016](0016-servo-power.md)을 다시 계산한다 (0027) | 기준: 서보 전원을 정할 때 |
| 상태 흐름 | 박자마다 내고 클라이언트마다 솎는다 (0023) | 메시지 형식: 0023을 만들 때 |

### 만드는 순서

실물이 없어도 되는 것부터 가짜 서보로 만든다. 시간은 가짜 시계로 흉내 내서 시험이 바로 끝나게 한다.

1. 루프 뼈대: 한 박자(상태 읽기 → 검사 → 목표 쓰기), 궤적 실행과 거부, 정지와 버티기, 보호 비트와 통신 실패에 고장. 끝났다 (2026-11-14, `crates/controller/src/runloop.rs`).
   - 정지는 같은 길을 따라가며 재생 빠르기를 정지 시간 동안 0으로 줄인다. 점 사이는 곧게 잇는다.
   - 고장은 서보 보호 비트, 꺼진 토크, 상태를 3박자 잇달아 읽지 못함이다. 새 목표를 쓰지 않고(서보는 마지막 목표를 잡고 있다) 까닭을 남기며, 사람이 풀 때 관절 층의 시작 절차로 다시 켜거나 이어받는다.
   - 움직이는 중에는 새 궤적을 받지 않는다 (이어 붙이기는 경로 계획을 만들 때 정한다).
   - 한계값(속도 한계, 첫 점이 지금 목표에서 떨어져도 되는 크기, 정지 시간)은 지금은 루프를 만들 때 주고, 2번에서 로봇 설정으로 옮긴다.
2. 온도와 전압 기준, 관절마다 토크 한도, 처짐 보정 자리 (값은 로봇 설정에 두고, 재기 전에는 비워 두거나 시험값이라고 표시한다). 끝났다 (2026-11-14).
   - 로봇 설정의 `[run_loop]`: 속도 한계, 첫 점이 지금 목표에서 떨어져도 되는 크기, 정지 시간, 온도 알림과 쉬기 기준, 전압 알림 기준, 처짐 보정의 이득과 최대 크기. 값은 모두 시험값이다 (처음 움직일 때 느리고 조심스럽게).
   - 관절마다 `torque_limit_percent`: 토크를 켤 때 쓴다. 관절 층의 상한보다 크면 상한을 쓴다. 값은 팔 전체 모델로 잡을 때까지 비워 둔다.
   - 온도: 쉬는 기준에 닿으면 정지해 버티고, 알림 기준 아래로 식을 때까지 새 궤적을 받지 않는다. 쉬는 자세가 정해지면 그리로 내린다. 알림 기준을 넘은 온도와 기준보다 낮은 전압은 알림 목록에 낸다.
   - 처짐 보정: 붙잡고 있는 동안만 쌓고, 움직이는 동안은 쌓은 값을 그대로 쓴다. 이득이 0이면 끈다 (지금은 꺼 둔다).
3. 그리퍼 서보. 끝났다 (2026-11-14).
   - 로봇 설정의 `[gripper]`: ID(11~19), 피니언 반지름과 다 벌린 폭(설계 값, [0030](0030-parallel-gripper.md)), 쥐는 힘, 빠르기, 판정 허용 폭, 그리고 닫은 자리(손가락이 맞닿은 자리)를 영점처럼 잰 값. 서보는 관절처럼 검사하고(영점 범위, 위치 오프셋), 쥐는 힘이 과부하 기준보다 낮아야 읽힌다 (쥔 채 버티면 서보 보호가 걸린다). 로봇 설정에는 그리퍼를 달 때 더한다.
   - 루프는 그리퍼 서보를 같은 박자로 읽고 쓰고, 정한 빠르기로 목표 폭까지 간다. 목표 폭을 쓴 다음 박자부터 판정한다: 목표 폭에서 허용 폭 안이면 닿음, 그 전에 멈춘 채 토크 한도의 80 % 넘게 밀고 있으면 잡음. 정지와 고장에도 쥔 채 둔다.
   - 못 잡음(정한 시간 안에 판정이 나지 않음)과 명령마다 힘과 빠르기를 주는 것은 0023의 메시지를 만들 때 더한다.
4. 시뮬레이션 백엔드와 메시지 (0025의 팔 움직이기 단계). 경로 계획과 함께 [0033](0033-planning-and-simulation.md)의 만드는 순서로 한다.
5. 실물: 서보 7개의 통신 시간으로 주기를 정하고, 관절 하나부터 낮은 토크 한도와 느린 속도로 움직인다 (0009의 실물 전 시험).

## 근거

- 할 일을 한 표에 두면 루프를 만들 때 빠뜨리지 않고, 어느 값이 실물을 기다리는지 한눈에 보인다.
- 실물 값(주기, 온도 기준, 토크 한도, 보정 방식)을 기다리지 않고 루프의 모양을 먼저 만든다. 값은 로봇 설정에 두어, 재면 숫자만 바꾼다.
