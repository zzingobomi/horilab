# 0005. 하드웨어 연결 구조

- 상태: 대체됨 ([0025](0025-controller-on-pi.md))
- 날짜: 2026-11-07

## 배경

- 로봇 책상과 데스크톱 PC(Windows)가 3~5 m 떨어져 있고, 방 공간 때문에 가까이 둘 수 없다.
- D405는 USB 3 장치다. Intel은 케이블을 짧게(1 m 이하 권장) 쓰고, 2 m가 넘으면 단순 연장선 대신 USB 3 리피터 케이블과 자체 전원 허브를 쓰라고 권한다. 리피터는 제품마다 품질 차이가 크다. 서보 어댑터는 USB 2라 5 m까지 규격 안이다.
- 이전 프로젝트는 PC에 직접 연결했다가, D405와 모터를 같이 돌릴 때 모터 통신이 끊기는 문제를 겪고 라즈베리파이로 나눴다. 원인이 USB 경합인지 계산 부하인지는 가려지지 않았다. 파이 배포는 번거로웠다 ([background.md](../background.md#이전-프로젝트의-연결-구조)).
- 라즈베리파이 4B 4GB를 3대 가지고 있다. 추가 부품 예산은 빠듯하다 ([0004](0004-purchasing.md)).

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. 서보와 D405를 모두 PC에 USB로 직접 연결 (5 m USB 3 리피터 + 로봇 쪽 전원 허브) | 소프트웨어가 가장 단순하다 | 리피터와 허브를 사야 한다 (약 4.5만 원). 리피터 품질에 따라 끊길 수 있다. 이전 프로젝트의 문제가 같은 PC에서 다시 날 수 있다 |
| B. 이전 프로젝트 구조: 파이가 모터 제어 루프를 돌리고, 카메라는 다른 파이, PC는 상위 판단 | 살 것이 없다. 모터 루프가 PC 부하와 상관없이 일정하다. 실제로 돌아간 구조다 | 자주 고치는 모터 코드를 매번 파이로 옮겨 맞춰야 한다. 여러 기기를 오가며 디버깅한다 |
| C. 서보는 PC에 USB 2로 직접, D405는 로봇 옆 파이에 꽂고 유선 랜으로 PC에 보낸다 | 거의 살 것이 없다 (5 m USB 2 케이블). D405가 PC의 USB를 쓰지 않아 이전 프로젝트의 USB 문제가 생길 수 없다. 자주 고치는 코드가 PC에서 바로 돈다 | 카메라 영상을 네트워크로 받는 부분이 생긴다. PC가 바쁘면 모터 루프가 밀릴 수 있다 |

## 결정

C로 한다.

- 서보 어댑터는 5 m USB 2 케이블로 PC에 연결한다.
- D405는 로봇 옆 라즈베리파이 4에 연결하고, 파이는 유선 랜으로 PC에 영상을 보낸다. 와이파이는 깊이 영상을 감당하기 어려워 쓰지 않는다. 파이의 카메라 프로그램은 파이가 켜지면 자동으로 실행되게 설치한다.
- 모터 제어, IK, 경로 계산, 영상 처리는 PC에서 한다.
- 모터 제어는 영상 처리와 다른 프로세스에서 돌린다.
- 모터 제어 부분은 PC와 파이 어디서든 같은 코드로 돌 수 있게 경계를 나눈다.
- 프로그램은 기본으로 시뮬레이션만 움직이고, 실물은 명시적으로 켰을 때만 움직인다.

## 근거

- 자주 고치는 코드(모터 제어, IK, 경로 계산)가 PC에 있어서 고치고 바로 실행할 수 있다. 파이에는 거의 바뀌지 않는 카메라 프로그램만 있어서 배포 수고가 적다.
- 이전 프로젝트에서 원인을 못 가린 USB 문제를 구조적으로 피한다.
- 비용이 거의 들지 않고, 가진 파이를 쓴다.
- 영상은 조금 늦게 와도 되지만 모터 명령은 그러면 안 된다. 그래서 네트워크에는 영상만 지나가게 한다.

## 영향

- 서보와 연결 준비 단계(제작 로드맵 2단계)에서 시험한다. PC에서 영상 처리를 돌려 부하를 건 채 서보를 계속 읽고 쓰며 몇 시간 돌리고, 모터 명령 간격의 흔들림, 서보 통신 에러, 영상 누락과 끊김을 기록한다.
- 모터 명령 간격이 크게 흔들리면 모터 제어를 파이로 옮긴다 (B). 그때는 PC에서 명령 하나로 코드를 파이에 보내고 재시작하는 배포 스크립트와 VS Code 원격 접속으로 배포 수고를 줄인다.
- 카메라용 파이(hori2)에 빌드해 둔 pyrealsense2를 다시 쓸 수 있는지 확인한다. 이전 프로젝트 당시 ARM용 공식 패키지가 없어 소스 빌드했다.
- 손목에서 파이까지 가는 D405 케이블 규칙은 [design.md](../design.md#d405-케이블)에 있다.
- 사야 할 것: 5 m USB 2 케이블 (어댑터 쪽 커넥터는 보드 모델 확인 후), 필요하면 랜 케이블.
