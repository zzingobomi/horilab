# 0018. D405 맞춤 구조와 카메라 기둥

- 상태: 제안
- 날짜: 2026-11-07

## 배경

- D405 하나로 손목 카메라(eye-in-hand) 작업과 책상의 카메라 기둥(eye-to-hand) 작업을 다 한다. 두 자리 사이를 공구 없이 옮겨 달고, 다시 달아도 같은 자리에 들어가야 한다 ([goals.md](../goals.md#그럴듯한-팔의-기준)). 같은 자리에 들어가면 캘리브레이션은 자리마다 한 번만 한다.
- 손목 자리는 J6 집 옆이고, 광축을 도구 축 쪽으로 20° 기울인다 ([0013](0013-wrist-type.md), [0017](0017-skeleton.md)). 손목에 단 D405의 무게는 J5의 백래시를 늘 한쪽으로 누른다 ([0013](0013-wrist-type.md)).
- D405 ([hardware.md](../hardware.md#d405), 공식 사양서와 CAD):
  - 뒷면에 M3 구멍 두 개가 있다 (간격 20 mm, 나사가 최대 4 mm 들어감). 바닥에는 1/4-20 구멍 하나가 있다.
  - 커넥터는 옆면의 USB 3 Micro-B다.
  - 시야는 84° × 58°이고, 50 cm 안에서 깊이 오차가 ±2%다.
- 다시 달 때 각도가 조금만 달라져도 멀리서는 크게 어긋난다. 카메라가 책상에서 45 cm 떨어져 있으면 0.1°가 책상에서 0.8 mm다.
- 카메라 자리 검토 (`uv run python -m horilab_design.studies.cameras`): 기둥 카메라 자리 후보마다 아래를 봤다.
  - 작업 자리가 시야와 깊이 50 cm 안에 드는지. 작업 자리는 집는 곳의 박스 윗면, 팔레트 1~4층의 윗면, 앞쪽 잡기 자리다.
  - 팔을 비켜 두었을 때 팔이 작업 자리를 가리지 않는지
  - 작업 자세가 기둥에 막히는지. 박스 쌓기 34개(실제 방위), 박스를 옮기는 길 22개, 포인터 시험 17개, 비스듬히 잡기 54개를 봤다.
  - 팔을 곧게 세우고(J2 = J3 = 0) J1과 J4를 돌릴 때 기둥에 닿는지. 모두 284개 조합이다.
  - 플랜지에 단 보드(100 × 80 mm)로 캘리브레이션 자세가 몇 개 나오는지. 보드를 시야 안 15곳에 두고, 면을 카메라 쪽에서 0°·25°·40°(네 방향) 기울이고, 네 방향으로 돌려 540개 자세를 만들었다. 기울기와 방향의 종류는 9가지다.
  - 팔 형상은 0017의 배치 검토 형상이다. 책상 가장자리에서 베이스 중심까지는 6 cm로 어림했다.

- 곧게 선 팔은 손목(J5)이 높이 약 50 cm에 오고, 도구 끝은 65 cm까지 올라간다. 카메라가 작업 자리 바로 위에 있으면 J1을 돌릴 때 카메라나 가로 팔에 닿는다. 맞은편으로 8 cm 비키면 닿지 않는다.
- 보드를 다는 방식:
  - 판 면이 도구 축 방향을 보면, 맞은편으로 비킨 45 cm 자리에서 자세가 13개(5종류)만 나온다.
  - 판을 도구 옆(도구 축에서 9 cm)에 두고 면이 플랜지 쪽을 보게 달면 80개(9종류)가 나온다. 도구가 아래를 향하면 이 면은 위를 본다.
- 손목 카메라 캘리브레이션은 책상 앞쪽 가운데에 둔 7 × 5 보드(25 mm 칸)로 본다. 거리 25·35 cm에서 34방향을 봤다.
  - 포인터나 흡착을 달면 17방향이 되고, 기울이는 방향 8개 중 7개가 들어 있다. 나머지 17방향은 관절 범위 밖이다.
  - 평행 그리퍼를 달면 그리퍼가 보드 칸 모서리의 약 30%를 가린다.
  - 위의 기둥이 있어도 17방향이 그대로 된다.

## 검토한 대안

| 정할 것 | 대안 | 판단 |
|---|---|---|
| 맞춤 구조 | 맞춤 핀 2개 + 맞닿는 면 + 손나사 | 출력 구멍과 핀 사이 틈만큼 각도가 흔들린다. 핀 간격 20 mm에 틈 0.05 mm면 0.14°이고, 45 cm 아래 책상에서 1.1 mm다 |
| | 도브테일 슬라이드 + 끝 멈춤 + 손나사 | 미끄럼 틈 때문에 다시 달 때마다 각도가 조금씩 다르다 |
| | 강철 볼 3개를 강철 볼 두 개씩 짝지은 홈 3곳에 앉힘 (키네마틱 커플링) + 손나사 | 볼이 앉는 자리가 한 가지라서 출력물의 틈과 상관없이 같은 자리에 들어간다. 강철 볼을 사야 한다 |
| 누르는 힘 | 자석 | 붙이고 떼기가 가장 빠르다. 손목 받침이 J6 서보 바로 옆이라 서보의 위치 센서에 영향을 줄 수 있는데, 확인하지 못했다 |
| | 손으로 돌리는 나사 하나 | 몇 바퀴 돌려야 하지만 팔이 움직이는 중에 빠질 일이 없다 |
| 기둥 카메라 자리 | 작업 자리 위에서 내려다봄 | 박스 윗면과 팔레트 칸 안쪽이 옆 박스에 가리지 않는다. 카메라를 작업 자리 위로 내미는 가로 팔이 필요하다 |
| | 맞은편 모서리에서 비스듬히 봄 | 가로 팔이 없다. 팔레트까지 깊이가 49 cm로 정확도 범위의 끝이다. 팔레트 4층은 수평에서 약 20° 위에서 보게 되어 박스 윗면이 납작하게 보이고, 칸 안쪽을 옆 박스가 가릴 수 있다 |
| 케이블 | 손목용과 기둥용을 따로 두고 카메라 쪽 플러그를 바꿔 꽂는다 | 이음이 없고 팔 안 배선은 그대로다. 옮길 때마다 카메라 커넥터를 한 번 뺐다 꽂는다 |
| | 카메라에 짧은 케이블을 꽂아 둔 채 손목과 기둥의 연장선에 잇는다 | 카메라 커넥터는 그대로지만 USB 3 이음이 하나 늘고 전체 길이가 길어진다 ([0005](0005-connection-architecture.md)의 권장 길이) |
| | 케이블 하나를 팔 밖 클립에 끼워 다니다 옮겨 끼운다 | 케이블이 팔 밖으로 보이고, 옮길 때 오래 걸린다 |
| D405가 기둥에 가 있을 때 손목 받침 | 비워 둔다 | J5를 누르던 무게가 빠져 J5 백래시가 한쪽으로 붙지 않는다 |
| | D405와 같은 무게의 빈 맞춤판을 끼운다 | 출력물에 가진 너트를 넣어 만든다 |

## 결정 (제안)

- D405 뒷면에 맞춤판을 M3 나사 두 개로 붙여 두고 떼지 않는다. 나사가 카메라에 4 mm보다 깊이 들어가지 않게 판 두께를 정한다. 가진 M3 10 mm 볼트를 쓰면 머리 아래 판 두께가 6 mm 이상이어야 한다.
- 맞춤판에는 강철 볼 3개를 박는다. 받침에는 강철 볼을 두 개씩 짝지은 홈 3곳을 둔다. 고정은 손으로 돌리는 나사 하나로 한다. 자석은 쓰지 않는다.
- 손목과 기둥에 같은 받침을 둔다. D405가 기둥에 가 있으면 손목 받침에는 D405와 같은 무게(60 g)의 빈 맞춤판을 끼운다.
- 기둥 카메라 자리:
  - 렌즈는 작업 자리 가운데(로봇 앞 14 cm)보다 8 cm 맞은편, 높이 45 cm에 둔다. 광축은 작업 자리 가운데를 겨누므로 수직에서 약 10° 기운다. 넓은 쪽(84°)은 책상 긴 변 방향이다.
  - 기둥은 책상 맞은편 모서리에 세우고, 가로 팔로 카메라를 작업 자리 위에 둔다. 왼쪽 모서리와 오른쪽 모서리는 검토 결과가 같아서, 책상을 보고 고른다.
- 캘리브레이션:
  - 기둥 카메라는 도구 옆에 위를 보는 보드를 단 출력 도구로 한다.
  - 손목 카메라는 포인터나 흡착을 단 채 책상 위 보드로 한다.
- 케이블은 손목용(팔 안으로 지나감)과 기둥용(D405 기본 케이블)을 따로 둔다. 옮길 때는 카메라 쪽 플러그를 바꿔 꽂고, 카메라가 없는 동안 케이블 끝은 받침 옆에 끼워 둔다.

## 근거

- 기둥 카메라에서는 0.1°가 책상에서 0.8 mm라서, 다시 달았을 때 각도가 같아야 한다.
  - 키네마틱 커플링은 볼과 볼이 맞닿는 여섯 점으로 위치와 각도를 한 가지로 정한다. 그래서 핀과 구멍의 틈 같은 출력 공차가 들어가지 않는다.
  - 실제로 얼마나 같은 자리에 들어가는지는 받침을 출력해 잰다. 기둥에 단 D405로 보드를 보면서 10번 떼었다 붙이고, 보드 자세가 얼마나 바뀌는지 본다.
- 맞은편으로 8 cm 비킨 45 cm 자리는 검토한 항목을 모두 통과한 자리 중에서 캘리브레이션 자세가 많다.
  - 작업 자리가 깊이 29~46 cm 안에 든다. 사양서가 정확도를 주는 범위(50 cm) 안이다.
  - 박스 쌓기, 옮기는 길, 포인터 시험, 잡기, 두 캘리브레이션 자세가 모두 기둥에 막히지 않는다.
  - 곧게 선 팔에도 닿지 않아서, 경로 계획이 기둥을 피하기만 하면 된다.
- 옆 보드를 쓰면 도구가 아래를 향한 평소 자세 근처에서 보드가 카메라를 본다. 판 면이 도구 축을 보면 도구가 위를 향해야 해서 자세가 적다.
- 케이블 두 개는 새로 살 것이 손목용 하나뿐이다. 손목용은 원래 사기로 한 것이다 ([design.md](../design.md#d405-케이블)).

## 영향

- 손목에서는 맞춤판과 받침의 두께만큼 D405가 J6 집에서 멀어진다. 받침을 그릴 때 배치 검토를 다시 한다. 볼 것은 아래 다섯 가지다.
  - 0017의 D405 자리와 시야
  - 어댑터 둘레의 틈
  - 손나사에 손이 들어가는지
  - 빈 맞춤판을 끼운 손목
  - J5를 누르는 무게
- [design.md](../design.md#d405-케이블)의 D405 케이블 항목을 케이블 두 개로 고친다.
- 살 것: 강철 볼 (지름 6 mm 안팎). 볼을 눌러 끼울 구멍은 공차 시험편으로 정한다.
- 기둥은 책상 사진과 치수를 받은 뒤 설계한다. 클램프 자리는 베이스와 같이 정한다. 책상 가장자리에서 베이스까지의 실제 거리로 이 검토를 다시 돌린다.
- 기둥용 케이블 길이(기본 케이블 1 m)는 기둥과 카메라용 파이의 자리를 정할 때 본다. 카메라에서 가로 팔과 기둥을 따라 내려오면 약 0.8 m가 든다.
- USB 카메라도 맞춤판을 만들면 같은 받침에 달 수 있다. 크기는 실물을 잰 뒤에 정한다.
