# 0035. 출력 준비 자동화: 설정 실수를 막고 출력 판을 줄인다

- 상태: 채택
- 날짜: 2026-11-14

## 목표

- 출력 설정의 사람 실수를 없앤다: 프리셋, 판 종류, 필라멘트, 방향, 채움을 사람이 고르지 않는다.
- 공차를 잰 출력 품질을 그대로 지킨다. 출력 횟수를 줄이는 것보다 먼저다.
- 같은 색, 같은 프리셋 부품을 판에 모아 출력 횟수, 판 바꾸기, 필라멘트 바꾸기를 줄인다.
- 사람은 파일을 열어 출력을 누르고, 첫 층을 본다.
- 검사에 하나라도 걸리면 파일을 내지 않는다. 기본값으로 바꾸거나 일부 부품만 빼고 진행하지 않는다.

## 만든 것

- 출력 준비 도구 `packages/design/src/horilab_design/slicing.py`:
  - `uv run python -m horilab_design.slicing plan --name <묶음> <부품...>`: 부품은 `wrist`(그 모듈의 출력 부품 모두), `wrist.wrist_body:2`(n벌), `coupons.fit3_6806_bores@white`(시험편은 색을 붙인다)로 준다. 모든 판이 통과해야 `build/print/<묶음>/`에 판마다 3MF, 판 그림, `plan.json`을 낸다. 하나라도 걸리면 그 폴더를 지우고 아무것도 내지 않는다.
  - `uv run python -m horilab_design.slicing reference <화면에서 잘라 저장한 3MF>`: 가정 B. 화면 3MF를 모델 자리 그대로 명령 모드로 다시 잘라 견주고, 같으면 설정 전체의 지문을 알려 준다.
- 값 파일 `params/print.toml`: 앱·프리셋 묶음 판, 펼친 프리셋 내용의 지문, 프린터·필라멘트·공정 프리셋, 판 종류, 설정 전체의 지문(가정 B 뒤에 적는다), 핵심 설정, 무해한 로그 줄.
- 부품 모듈마다 파일 이름별 한글 이름 `LABELS` (모든 출력 부품에 있는지 각 모듈의 시험이 본다).
- 출력 안내 페이지 `uv run python -m horilab_design.pages.print_page <묶음>` → `build/pages/print_<묶음>.html`.

## 시험 결과 (2026-11-14)

- 가정 A 통과: `--curr-bed-type "Textured PEI Plate"`로 3MF에 텍스처 PEI가 들어가고 G-code가 55 °C로 데운다 (M140/M190 S55). 밑줄로 쓴 `--curr_bed_type`은 모르는 옵션으로 거절된다.
- 가정 C 통과: 사용자 폴더와 설치 폴더의 프리셋 묶음 판이 둘 다 02.04.00.01이고, 펼친 프린터·Strength·Standard·필라멘트 프리셋이 한 칸도 다르지 않다. 도구는 사용자 폴더의 것을 읽는다.
- 같은 프리셋으로 다른 부품, 다른 개수, 다른 색을 자른 두 판의 설정은 필라멘트 색 한 칸만 달랐다. 색만 빼면 지문 하나로 그 프리셋의 모든 판을 본다.
- 시험편 하나를 도구로 끝까지 자르면, 아직 적지 않은 설정 전체의 지문 말고는 모든 검사(앱·프리셋 판, 프리셋 내용, 판 종류와 바닥 온도, 핵심 설정, 방향, 로그, 부품 대조)를 통과한다.
- 가정 B는 사람이 화면에서 자른 3MF가 있어야 한다. 그 전에는 지문이 비어 있어 도구가 뽑을 파일을 내지 않는다. 가정 D는 처음 낸 3MF로, 가정 E는 첫 관절을 뽑을 때 본다.

## 시험할 가정

| | 가정 | 시험 | 통과 조건 |
|---|---|---|---|
| A | 명령 줄로 판 종류를 줄 수 있다 | 시험편을 `--curr-bed-type "Textured PEI Plate"`로 자른다 | 3MF의 `curr_bed_type`이 "Textured PEI Plate"이고, G-code의 첫 바닥 온도 명령이 55 °C다 (PLA, 텍스처 PEI) |
| B | 명령 모드 결과가 화면 결과와 같다 | 사람이 화면에서 시험편 하나를 늘 쓰던 설정(텍스처 PEI)으로 잘라 3MF로 저장한다. 같은 STL을 명령 모드로 자른다 | 설정 500칸이 같다 (파일 경로·시각처럼 출력과 상관없는 칸은 이름을 적어 뺀다). 예상 시간과 무게가 같다. G-code의 움직임 줄이 주석과 머리말을 빼고 같다 |
| C | 화면이 쓰는 프리셋과 도구가 읽는 프리셋이 같다 | 사용자 폴더와 설치 폴더의 프리셋을 펼쳐 견준다 | 프리셋 묶음 판이 02.04.00.01이고, 펼친 내용의 지문이 같다. 다르면 사용자 폴더의 것을 쓰고 B를 다시 한다 |
| D | 만든 3MF가 바로 뽑힌다 | 사람이 3MF를 더블클릭한다 | 묻는 창 없이 열리고, 판이 잘린 상태로 출력 버튼이 바로 눌린다 |
| E | 판에 모아 뽑아도 맞춤이 같다 | 첫 묶음 판에 6806 구멍 시험편을 같이 넣는다 | 고른 칸과 그 옆 칸의 판정(힘의 단계, [manufacturing.md](../manufacturing.md#공차))이 처음 시험편과 같다 |

## 위험과 막는 법

| 위험 | 막는 법 |
|---|---|
| 판 종류가 틀린다: 명령 모드의 기본값이 쿨 플레이트(PLA 바닥 35 °C)다. 프린터에 딸려 온 판은 텍스처 PEI(55 °C)다. 틀리면 첫 층이 안 붙고, 시험편과 첫 층 치수가 달라진다 | 판 종류를 값 파일에 두고 명령 줄로 준다 (가정 A). 3MF와 G-code에서 다시 읽는다. 안내 페이지에 보인다 |
| 화면과 다른 프리셋이나 기본값으로 자른다 | 앱 판, 프리셋 묶음 판, 펼친 프리셋 내용의 지문을 따로 고정한다. 처음 한 번 화면 결과와 칸 전체, 시간, 무게, G-code를 견준다 (가정 B, C). 그 뒤로는 자를 때마다 칸 전체의 지문을 본다 |
| 핵심 설정이 바뀐다 | 공차에 닿는 칸은 지문과 따로 값으로 견준다: 노즐 지름, 층 높이, 첫 층 높이, 벽 수, 바깥 벽 속도, 채움 밀도와 무늬, 윗면·아랫면 층, 노즐 온도(첫 층 포함), 판 종류와 그 바닥 온도(첫 층 포함), 냉각(팬 속도, 층 시간 감속), 서포트, 구멍·외곽 보정, 첫 층 보정(elephant foot), 필라멘트 밀도 |
| 스튜디오가 업데이트된다 | 판이 다르면 자르지 않는다. 업데이트 알림이 떠도 누르지 않는다 |
| 화면이면 보였을 경고를 놓친다 | 로그 검사와 3MF 검사를 따로 둔다. `[error]`는 막는다. 무해하다고 확인한 줄은 문구와 조건을 정확히 적어서만 뺀다 (지금은 P1S에서 늘 나는 `nozzle_volume_type not found ... extruder_count 1` 하나). 처음 보는 경고가 나오면 그 판은 "검토 필요"로 막는다 |
| 서포트가 필요한 모양인데 서포트를 껐다 | 부품마다 `printcheck.py`의 걸침 검사(바닥에 닿지 않고 아래를 보는 면)를 보고에 넣는다. 슬라이서 경고도 위처럼 막는다. 고칠 때는 서포트보다 출력 방향이나 모양을 먼저 본다 ([manufacturing.md](../manufacturing.md#프린터-제약)) |
| 한 판에 모은 부품 하나가 떨어져 다른 부품까지 망친다 | 출력 중 부품 빼기와 자동 바닥 테두리가 켜져 있지만, 실패를 막아 주지는 않는다. 안내 페이지에 부품마다 높이와 바닥에 닿는 넓이를 보이고, 높고 바닥이 좁은 부품을 표시한다 (참고값이다) |
| 판에 모으면 층마다 식는 시간이 달라 치수가 달라질 수 있다 | 따로 실험하지 않고, 첫 묶음 판에 시험편을 같이 뽑아 본다 (가정 E) |
| 부품이 빠지거나, 구조용과 덮개용이 섞인다 | 코드의 부품 목록(개수 포함)과 판마다 들어간 부품을 대조한다. 한 판에는 한 프리셋만 둔다 |
| 판이 여럿 든 3MF에서 판 하나를 빠뜨린다 | 판마다 3MF를 따로 낸다 |
| 출력 전에 화면에서 설정을 바꾼다 | 막을 수 없다. 안내에 "출력만 누른다"를 쓴다. 다시 잘라도 3MF에 든 설정이라 같다 |
| 옛 파일이나 다른 파일을 뽑는다 | 알리기 직전에 지금 코드로 다시 만든다 (design.md의 8). 파일 이름 끝에 지문 앞 6자리를 넣어, 프린터 화면의 이름과 안내 페이지를 눈으로 맞춘다 |
| 필라멘트 색을 틀린다 | 파일 이름 맨 앞에 순서와 색을 쓰고, 안내에 크게 보인다 |
| 출력 범위를 넘는다 | 부품 높이와 판 밖 여부를 본다 (P1S 256 mm) |

## 사람이 확인할 것

- 처음 한 번: 화면에서 시험편 하나를 잘라 3MF로 저장 (가정 B). 만든 3MF를 더블클릭해 바로 뽑히는지 (가정 D). 첫 묶음 판의 시험편 판정 (가정 E).
- 출력할 때마다:
  1. 파일 이름의 색과 같은 필라멘트를 끼웠는지.
  2. 출력 창에서 AMS를 끄고(외부 스풀), 다른 설정은 건드리지 않는다. 판은 텍스처 PEI다 (가진 판은 이것 하나다).
  3. 프린터 화면의 파일 이름 끝 6자리가 안내 페이지와 같은지.
  4. 첫 층이 잘 붙는지 본다. 떨어진 부품은 프린터 화면에서 그 부품만 뺀다.
  5. 끝나면 대화창에 알린다.

## 사용 흐름

- 사용자는 명령을 치지 않는다. Claude가 도구를 돌리고, 결과를 출력 안내 페이지로 보인다.
- 파일은 판마다 3MF 하나다. 이름은 순서, 색, 지문 앞 6자리다 (예: `01-black-a3f9c2.3mf`). 프린터 화면이 한글을 못 보일 수 있어 영어로 쓴다.
- 출력 안내 페이지 (판마다): 스튜디오가 그린 판 그림, 부품의 한글 이름과 파일 이름, 부품마다 높이와 바닥 넓이, 넣을 필라멘트, 판 종류, 부품 수, 시간과 무게, 파일 지문, 출력할 때마다 할 확인.
- 순서: 같은 프리셋끼리, 같은 색끼리 묶고, 먼저 조립할 부품이 먼저 나오게 한다. 필라멘트를 덜 바꾸게 같은 색 판을 이어서 둔다. 긴 판은 밤에 돌리게 표시한다.
- 대화창에는 판 수, 전체 시간, 첫 판, 안내 페이지 링크만 쓴다.

## 하지 않는 것

- 구조용과 덮개용을 한 판에 섞기 (위 "묶기").
- 단독 출력과 여러 부품 출력의 치수 비교 실험: 가정 E의 시험편 하나로 같은 질문에 답한다.
- 부품 간격(브림 포함) 검사기: 배치는 스튜디오가 화면과 같은 방식으로 한다.
- 얇은 벽 분석기: 설계 규칙과 슬라이서 경고로 본다.
- 화면에서 설정을 못 바꾸게 막기: 막을 방법이 없다.
- 사람이 해시 전체를 대조하기: 파일 이름의 6자리로 충분하다.

## 처음 시제품에서 본 것

- 판 종류와 프리셋 위치 문제는 처음 시제품의 결과를 보고 찾았다.
- 첫 관절의 out_disc를 자를 때 스튜디오가 "ZFiller: encounter idx from clip" 오류를 냈다. 다른 부품은 깨끗했다. out_disc에는 높이 3.8 mm와 3.81 mm에 수평면이 0.01 mm 차이로 둘 있어, 이 얇은 턱이 원인으로 보인다 (확인 전). 이 메시지를 설명한 자료는 찾지 못했다. 뽑을 파일을 낼 때 고친다 ([status.md](../status.md)).
