# UR3e 충돌 형상

UR3e와 견주는 검토 코드(`studies/ur3e.py`, [0027](../../../../../../../docs/decisions/0027-general-purpose-review.md))가 쓰는 UR3e 링크 형상이다.

- 출처: [Universal_Robots_ROS2_Description](https://github.com/UniversalRobots/Universal_Robots_ROS2_Description)의 `meshes/ur3e/collision/`, 커밋 `0eb1a861f7772fceb38510d90fa2f98ec668070c` (2026-11-03).
- 라이선스: BSD-3-Clause (같은 폴더의 `LICENSE`). 그 레포에서 UR의 별도 약관을 따르는 것은 UR15, UR20 같은 새 모델의 형상뿐이다.
- 파일은 받은 그대로다. 형상의 자리와 기구학 값은 `studies/ur3e.py`에 출처와 함께 적었다.
