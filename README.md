# horilab

3D 프린터로 출력한 부품과 Feetech 서보로 만드는 6축 로봇팔 호리봇(horibot).

**지금:** 0단계(공차 시험편, 서보 실측)를 마무리하며 Rust 컨트롤러와 관절 하나 시험을 준비하는 단계. 자세한 건 [진행 상황](docs/status.md).
